# ScoreShow

교사용 점수 확인 도구 (오프라인 전용)

안녕하세요.

이번에 수행평가 점수를 알려주면서 느꼈던 불편함을 해결하고 싶어서 작은 프로그램을 만들어봤습니다. 사실 바이브코딩(생활코딩)을 연습하면서 배운 것들을 활용해보고 싶은 마음도 있었고요.

**왜 만들게 되었나요?**

평소 수행평가 점수를 알려줄 때마다 느꼈던 불편함이 있었습니다. 나이스에서 출력한 점수 목록을 보여주려면 다른 학생들의 점수를 가려야 하는데, 종이로 출력해서 가려가며 보여주거나, 화면에서 손으로 가려가며 보여주는 것이 너무 번거로웠습니다. 특히 한 반에 30명이 넘는 학생들이 있을 때는 더욱 그랬죠.

그래서 이번에 바이브코딩을 연습하면서 "학생을 한 명씩만 보여주는 프로그램이면 어떨까?"라는 생각으로 시작하게 되었습니다. 개인 모니터에서 학생을 한 명씩 개별적으로 보여주면 비밀도 보호하고 편리하게 점수를 확인할 수 있을 것 같았거든요.

**실제로 사용해보니?**

이번 수행평가 때 먼저 사용해봤는데, 정말 편리했습니다! 엑셀 파일만 업로드하면 자동으로 학생 목록이 만들어지고, 발표 모드에서 화살표 키만 누르면 학생을 한 명씩 보여줄 수 있어서 시간도 절약되고 편했습니다. 특히 화이트아웃 기능으로 자연스럽게 학생을 전환할 수 있어서 더 좋았어요.

동료 교사분들도 불편하실 것 같아서 공유하고 싶어 올립니다.

## 기능

- 📊 엑셀 파일(.xlsx, .xls, .csv) 업로드 및 자동 컬럼 매핑
- 📥 표준 템플릿 다운로드/업로드 (나이스 다중 영역 인식 문제 대비)
- 👥 학생 목록 검색 및 관리
- 🎯 발표 모드 - 학생을 한 명씩 개별적으로 보여주어 점수를 명확하게 확인
- ✏️ 자물쇠를 해제해서 점수/만점을 직접 수정 (자동 저장)
- 🔒 100% 오프라인 동작 (네트워크 요청 완전 차단)
- 💾 IndexedDB 로컬 저장소 (AES 암호화 지원)
- 📱 PWA 지원 - 앱으로 설치 가능

## 표준 서식 템플릿 (다중 영역이 하나만 나올 때)

나이스 엑셀 파일은 형식 변수가 많아서 여러 평가 영역(쓰기1, 말하기, 듣기 등)이 모두 인식되지 않는 경우가 아직 있습니다. 이럴 때는 상단의 **"📄 표준 서식 다운로드"** 버튼을 이용하면 훨씬 안정적으로 모든 영역을 불러올 수 있습니다.

1. 나이스에서 기존처럼 엑셀을 내려받습니다.
2. ScoreShow에서 `표준 서식`을 다운로드합니다.
3. 템플릿의 `학년/반/번호/이름`과 `영역N 이름/점수/만점` 칸에 점수를 붙여넣습니다. (각 행마다 영역 이름을 써 주세요.)
4. 템플릿 파일을 그대로 업로드합니다.

표준 서식은 컬럼 구조가 고정되어 있어서, 영역1만 점수가 있어도 영역1만 보여주고, 영역2/3을 추가로 입력하면 그 이후 영역까지 모두 정확하게 파싱합니다.

## 점수 편집 모드 (자물쇠 잠금)

업로드한 점수를 바로 수정하고 싶을 때는 우측 패널의 **"🔒 점수 잠금 해제"** 버튼을 눌러 편집 모드를 켤 수 있습니다.

- 잠금 해제 시 영역 이름, 점수, 만점을 직접 입력할 수 있고 저장은 자동으로 이루어집니다.
- 실수 입력을 막고 싶을 때는 다시 잠그면 됩니다.
- 점수 입력 칸을 비우면 `미입력`으로 표시되어 빈 셀과 동일한 상태가 됩니다.

## 기술 스택

- React + Vite + TypeScript
- Tailwind CSS
- SheetJS (엑셀 파싱)
- Zustand (상태 관리)
- idb-keyval (IndexedDB)
- crypto-js (암호화)
- vite-plugin-pwa (PWA)

## 설치 및 실행

### 의존성 설치

```bash
pnpm install
```

### 개발 서버 실행

```bash
pnpm run dev
```

개발 서버가 `http://localhost:5173`에서 실행됩니다.

### 프로덕션 빌드

```bash
pnpm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다. 로컬 서버로 실행:

```bash
npx serve dist
```

### Electron 데스크톱 앱 빌드

**개발 모드로 Electron 앱 실행:**

```bash
# 터미널 1: Vite 개발 서버 실행
pnpm run dev

# 터미널 2: Electron 실행 (새 터미널)
pnpm run electron:dev
```

**설치 가능한 실행 파일 생성:**

```bash
pnpm run electron:pack
```

빌드된 파일은 `release` 폴더에 생성됩니다:

- Windows: `ScoreShow Setup 1.1.0.exe` ([바로 다운로드](https://github.com/pobydev/ScoreShow/releases/download/v1.1.0/ScoreShow.Setup.1.1.0.exe))
- Mac: `ScoreShow-1.1.0.dmg`
- Linux: `ScoreShow-1.1.0.AppImage`

일반 사용자는 이 실행 파일을 다운로드하여 더블클릭으로 설치하고 사용할 수 있습니다.

## 사용 방법

1. 엑셀 파일 업로드

   - `.xlsx`, `.xls`, `.csv` 형식 지원
   - 자동으로 컬럼 매핑 (학년, 반, 번호, 이름, 평가영역, 점수, 만점)
   - 나이스 엑셀에서 여러 영역이 하나만 표시되면, 상단의 `표준 서식`을 내려받아 점수를 붙여넣은 뒤 다시 업로드해주세요.

2. 학생 선택 및 미리보기

   - 좌측 목록에서 학생을 선택
   - 우측 패널에서 학생 정보와 점수 확인

3. 발표 모드
   - "발표 모드 시작" 버튼 클릭
   - 학생을 한 명씩 개별적으로 보여주어 비밀을 보호하면서 점수를 확인
   - 큰 폰트로 표시되어 정보를 확실하게 파악 가능
   - 화이트아웃 기능: 화살표 키를 한 번 누르면 화면이 비워지고, 같은 방향 키를 다시 누르면 다음/이전 학생으로 이동
     - 학생 전환 전 짧은 대기 시간을 제공하여 자연스러운 전환 효과
     - 학생 리스트에서 현재 전환 위치를 녹색 마커로 표시
   - 키보드 단축키:
     - `←` `→` `↑` `↓`: 학생 이동 (화이트아웃 포함)
     - `F`: 전체화면
     - `Esc`: 발표 모드 종료

## 🔒 보안 및 개인정보 보호

성적은 민감한 개인정보입니다. 그래서 이 부분을 특히 신경 썼습니다.

- ✅ 모든 데이터는 **이 컴퓨터의 로컬 저장소에만** 저장됩니다
- ✅ **외부 서버로 데이터가 전송되지 않습니다** (서버에 저장하지 않습니다)
- ✅ 네트워크 요청이 완전히 차단됩니다
- ✅ 사용 완료 후 "데이터 삭제" 버튼으로 모든 데이터를 즉시 삭제할 수 있습니다

**⚠️ 중요한 안내사항**

성적은 민감한 정보인 만큼, 프로그램 사용 시에도 항상 조심스럽게 다뤄주셨으면 합니다.

- 사용이 끝나면 반드시 "데이터 삭제" 버튼을 눌러주세요
- 다른 사람이 사용하는 컴퓨터에서는 사용을 피해주세요
- 가능하면 개인 컴퓨터나 교사 전용 컴퓨터에서만 사용하시기 바랍니다

이 프로그램이 편리하게 사용하실 수 있도록 최선을 다했지만, 성적 정보를 다루는 만큼 항상 주의 깊게 사용해주시면 감사하겠습니다.

## 파일 구조

```
src/
├── components/          # React 컴포넌트
│   ├── FilePicker.tsx   # 엑셀 업로드
│   ├── StudentList.tsx  # 학생 목록
│   ├── PreviewPanel.tsx # 미리보기 패널
│   └── Presenter.tsx    # 발표 모드
├── core/               # 핵심 로직
│   ├── parseExcel.worker.ts  # 엑셀 파서 (Web Worker)
│   ├── mapping.ts      # 컬럼 매핑
│   ├── normalize.ts    # 데이터 정규화
│   ├── storage.ts      # IndexedDB 저장소
│   └── no-network.ts   # 네트워크 차단
├── store/              # 상태 관리
│   └── store.ts        # Zustand 스토어
├── types/              # TypeScript 타입
│   └── index.ts
├── App.tsx             # 메인 앱
└── main.tsx            # 엔트리 포인트
```
