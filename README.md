# ScoreShow

“수행평가 점수 확인, 한 명씩 손쉽고 안전하게” 교사용 도구

안녕하세요.

이번에 수행평가 점수를 알려주면서 느꼈던 불편함을 해결하고 싶어서 작은 프로그램을 만들어봤습니다. 사실 바이브코딩(생활코딩)을 연습하면서 배운 것들을 활용해보고 싶은 마음도 있었고요.

**왜 만들게 되었나요?**

평소 수행평가 점수를 알려줄 때마다 느꼈던 불편함이 있었습니다. 나이스에서 출력한 점수 목록을 보여주려면 다른 학생들의 점수를 가려야 하는데, 종이로 출력해서 가려가며 보여주거나, 화면에서 손으로 가려가며 보여주는 것이 너무 번거로웠습니다. 특히 한 반에 30명이 넘는 학생들이 있을 때는 더욱 그랬죠.

그래서 이번에 바이브코딩을 연습하면서 "학생을 한 명씩만 보여주는 프로그램이면 어떨까?"라는 생각으로 시작하게 되었습니다. 개인 모니터에서 학생을 한 명씩 개별적으로 보여주면 비밀도 보호하고 편리하게 점수를 확인할 수 있을 것 같았거든요.

**실제로 사용해보니?**

이번 수행평가 때 먼저 사용해봤는데, 정말 편리했습니다! 엑셀 파일만 넣으면 자동으로 학생 목록이 만들어지고, 화살표 키만 누르면 학생을 한 명씩 보여줄 수 있어서 시간도 절약되고 편했습니다. 특히 학생 사이에 대기 화면을 거쳐서 다음 학생이 앞 학생의 점수를 보지 않게 되어 더 좋았어요.

동료 교사분들도 불편하실 것 같아서 공유하고 싶어 올립니다.

## 기능

- 📊 엑셀 파일(.xlsx, .xls) 업로드 및 자동 컬럼 매핑
- 🗂️ 반별 저장 목록 - 이름을 정해 저장해 두고 골라서 열기
- 📂 여러 파일이나 폴더를 한꺼번에 넣으면 파일마다 목록 하나씩 저장
- 📥 표준 템플릿 다운로드/업로드 (나이스 다중 영역 인식 문제 대비)
- 👥 학생 목록 검색 및 관리
- 🎯 학생을 한 명씩 큰 글씨로 보여 주고, 사이에 대기 화면으로 점수를 가림
- ✏️ 전체 점수표에서 점수/만점을 직접 수정 (자동 저장)
- 🔒 학생 정보는 이 컴퓨터 밖으로 나가지 않습니다
- 💾 IndexedDB 로컬 저장소 (AES 암호화 지원)
- 📱 PWA 지원 - 앱으로 설치 가능

## 표준 서식 템플릿 (다중 영역이 하나만 나올 때)

나이스 엑셀 파일은 형식 변수가 많아서 여러 평가 영역(쓰기1, 말하기, 듣기 등)이 모두 인식되지 않는 경우가 아직 있습니다. 이럴 때는 **스코어쇼 사용 가이드** 창의 **"표준 서식 받기"** 버튼을 이용하면 훨씬 안정적으로 모든 영역을 불러올 수 있습니다.

1. 나이스에서 기존처럼 엑셀을 내려받습니다.
2. ScoreShow에서 `표준 서식`을 다운로드합니다.
3. 템플릿의 `학년/반/번호/이름`과 `영역N 이름/점수/만점` 칸에 점수를 붙여넣습니다. (각 행마다 영역 이름을 써 주세요.)
4. 템플릿 파일을 그대로 업로드합니다.

표준 서식은 컬럼 구조가 고정되어 있어서, 영역1만 점수가 있어도 영역1만 보여주고, 영역2/3을 추가로 입력하면 그 이후 영역까지 모두 정확하게 파싱합니다.

## 점수 편집 모드 (자물쇠 잠금)

점수를 바로 수정하고 싶을 때는 **"점수 수정"** 버튼을 누르면 반 전체 점수가 표로 나옵니다.

- 수정 중에는 영역 이름, 점수, 만점을 직접 입력할 수 있습니다. 칸을 벗어나거나 Enter를 누르면 저장되고, 고친 칸에는 원래 값과 되돌리기가 나옵니다.
- 표에는 모든 학생의 점수가 보이므로 학생이 앞에 없을 때 열어 주세요. Esc를 누르면 바로 닫히고 대기 화면으로 갑니다.
- 점수 입력 칸을 비우면 `미입력`으로 표시되어 빈 셀과 동일한 상태가 됩니다.

## 기술 스택

- React + Vite + TypeScript
- Tailwind CSS
- SheetJS (엑셀 파싱)
- Zustand (상태 관리)
- idb-keyval (IndexedDB)
- crypto-js (암호화)
- vite-plugin-pwa (PWA)

## 설치 및 실행

### 의존성 설치

```bash
pnpm install
```

### 개발 서버 실행

```bash
pnpm run dev
```

개발 서버가 `http://localhost:5173`에서 실행됩니다.

### 프로덕션 빌드

```bash
pnpm run build
```

빌드된 파일은 `dist` 폴더에 생성됩니다. 로컬 서버로 실행:

```bash
npx serve dist
```

### Electron 데스크톱 앱 빌드

**개발 모드로 Electron 앱 실행:**

```bash
# 터미널 1: Vite 개발 서버 실행
pnpm run dev

# 터미널 2: Electron 실행 (새 터미널)
pnpm run electron:dev
```

**설치 가능한 실행 파일 생성:**

```bash
pnpm run electron:pack
```

빌드된 파일은 `release` 폴더에 생성됩니다. 배포하는 설치 파일은 Windows용뿐입니다:

- Windows: `ScoreShow-Setup-1.3.1.exe` ([바로 다운로드](https://github.com/pobydev/ScoreShow/releases/download/v1.3.1/ScoreShow-Setup-1.3.1.exe))

일반 사용자는 이 실행 파일을 다운로드하여 더블클릭으로 설치하고 사용할 수 있습니다.

## 사용 방법

1. 시작하기 전에 TV와 프로젝터를 끄거나 연결을 해제합니다.
2. 나이스에서 받은 엑셀 파일을 넣고 이름을 정해 저장합니다. 저장한 목록은 다음에 켤 때 왼쪽에서 고를 수 있습니다.
3. **점수 수정**으로 반 전체 점수가 맞는지 확인합니다.
4. 학생에게 보여 줍니다. 목록을 열면 대기 화면으로 시작합니다.
   - 학생이 모니터 앞에 오면 오른쪽 화살표 키를 눌러 점수를 보여 줍니다.
   - 확인이 끝나면 오른쪽 화살표 키를 한 번 더 눌러 대기 화면으로 돌아갑니다. 학생은 자리로 돌아가고 다음 학생이 나옵니다.
   - 오지 않은 학생은 나중에 명단에서 이름을 눌러 보여 줍니다.
   - 키보드 단축키:
     - `←` `→` `↑` `↓`: 대기 화면과 앞뒤 학생 이동
     - `F`: 전체화면
     - `Esc`: 바로 대기 화면
5. 모두 확인했으면 저장된 점수를 지웁니다.

자세한 내용은 [사용 가이드](./USER_GUIDE.md)에 있습니다.

## 🔒 보안 및 개인정보 보호

성적은 민감한 개인정보입니다. 그래서 이 부분을 특히 신경 썼습니다.

- ✅ 모든 데이터는 **이 컴퓨터의 로컬 저장소에만** 저장됩니다
- ✅ 학생 정보는 이 컴퓨터 밖으로 나가지 않습니다. 인터넷은 새 버전 확인에만 씁니다.
- ✅ 앱을 켜면 저장 목록만 보이고, 목록을 고르기 전에는 점수가 나오지 않습니다
- ✅ 목록을 하나씩 또는 모두 지울 수 있고, 30일이 지난 목록은 지울지 묻습니다

**⚠️ 중요한 안내사항**

성적은 민감한 정보인 만큼, 프로그램 사용 시에도 항상 조심스럽게 다뤄주셨으면 합니다.

- 비밀번호가 없어서 앱을 여는 사람은 저장된 점수를 볼 수 있습니다. 확인이 끝나면 저장된 점수를 지워주세요
- 다른 사람이 사용하는 컴퓨터에서는 사용을 피해주세요
- 가능하면 개인 컴퓨터나 교사 전용 컴퓨터에서만 사용하시기 바랍니다

이 프로그램이 편리하게 사용하실 수 있도록 최선을 다했지만, 성적 정보를 다루는 만큼 항상 주의 깊게 사용해주시면 감사하겠습니다.

## 파일 구조

```
src/
├── components/          # React 컴포넌트
│   ├── app/             # 창 맨 위 바, 안내 창, 파일 올리기
│   ├── home/            # 첫 화면, 저장 목록, 저장 창
│   ├── work/            # 학생 점수, 대기 화면, 전체 점수표
│   └── StudentList.tsx  # 학생 목록
├── core/               # 핵심 로직
│   ├── parser/         # 엑셀 파서
│   ├── lists.ts        # 저장 목록 계산
│   ├── mapping.ts      # 컬럼 매핑
│   ├── normalize.ts    # 데이터 정규화
│   ├── storage-secure.ts  # IndexedDB 저장소
│   └── no-network.ts   # 네트워크 차단
├── store/              # 상태 관리
│   └── store.ts        # Zustand 스토어
├── types/              # TypeScript 타입
│   └── index.ts
├── App.tsx             # 메인 앱
└── main.tsx            # 엔트리 포인트
```
