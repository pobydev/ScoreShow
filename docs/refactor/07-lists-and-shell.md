# 저장 목록과 어울림에 맞춘 틀

2026-10-31 사용자와 정한 내용입니다. `06-feature-inventory.md`의 기능 가운데 아래는 이렇게 바뀌었습니다. 시험은 `e2e/features.spec.mjs`, `e2e/rebuild.spec.mjs`, `e2e/lists.spec.mjs`에 있습니다.

## 쓰는 모습

교사는 TV와 프로젝터를 끄고, 학생이 한 명씩 교사 자리 모니터로 와서 자기 점수를 봅니다. 키는 교사가 누릅니다. 그래서 "발표"라는 말과 발표 모드를 없앴습니다.

## 대기 화면 규칙

대기 화면은 두 학생 사이입니다. 왼쪽 키는 막대 위 학생, 오른쪽 키는 막대 아래 학생을 보여 줍니다. 어느 쪽에서 왔는지는 기억하지 않습니다. 양 끝에서는 버튼이 하나입니다. 대기 화면 버튼과 Esc는 지금 학생 아래쪽 사이로 갑니다. 대기 화면에는 모래시계 그림(`src/assets/wait-hourglass.png`, 로고 화풍으로 생성, 움직임 없음), "대기 중입니다", 번호가 적힌 버튼만 나오고 이름은 없습니다. 모두 끝난 화면에는 그림을 넣지 않습니다. `F`는 한글 입력 상태에서도 동작하도록 키 위치(`e.code`)로 판단합니다.

건너뛰기와 확인 표시(✓, 못 봄)는 만들었다가 뺐습니다. 건너뛰기는 방향에 따라 대상이 달라져 헷갈렸고, 건너뛰기 없는 자동 확인 표시는 결석한 학생도 찍혀 믿을 수 없기 때문입니다 (2026-10-31 사용자 결정). 오지 않은 학생은 명단에서 이름을 눌러 보여 줍니다.

## 저장 형식

IndexedDB `scoreshow-lists`에 `{ id, cipher }` 배열을 둡니다. 목록마다 따로 암호화하므로 하나가 손상되어도 나머지는 읽습니다. 이름도 암호문 안에 있습니다. 복호화 키는 지금처럼 localStorage에 있어, 저장 파일을 직접 여는 것만 막습니다. 비밀번호는 사용자 결정으로 넣지 않습니다.

## 추천 이름

나이스 제목 줄의 `1학기`, `과목 : 과학` 또는 `2학년   1 과학`, 한 영역 파일의 `영역 : 탐구1`을 읽고, 학년과 반은 학생에서 가져옵니다. 찾지 못한 부분은 뺍니다. 교사가 고치는 추천이라 틀려도 점수에는 영향이 없습니다.

## 확인하지 못한 것

- 추천 이름을 실제 나이스 파일로 확인하지 못했습니다. 실제 파일을 본뜬 시험 자료로만 확인했습니다.
- TV를 실제로 연결했을 때의 안내(`screen.getAllDisplays`)와 화면 복제 상태
- 교실 모니터에서 은은한 바탕 그라데이션이 어떻게 보이는지
