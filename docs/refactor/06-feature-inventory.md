# 과제 D 기능 목록

화면을 새로 만들기 전에 지금 화면(`fc63a38`)에서 뽑은 기능 목록입니다. `USER_GUIDE.md`, `README.md`, `ScoreShow.md`, `docs/refactor/shots/capture.mjs`, `src/`를 대조했습니다. 문서와 코드가 다르면 **코드의 동작**을 기준으로 삼고 아래 "문서와 코드가 다른 곳"에 적었습니다.

각 항목의 ID는 `e2e/features.spec.mjs`의 시험 제목과 같습니다. 이 시험은 지금 화면과 새 화면에서 똑같이 통과해야 합니다. `RB-` 항목은 이번에 새로 요구된 화면 구조라 `e2e/rebuild.spec.mjs`에 있고, 새 화면에서만 통과합니다. 통과표는 `06-rebuild.md`에 있습니다.

## 시험하지 않는 항목

| 항목 | 이유 |
|------|------|
| `useOfflineLog` | 개발 빌드의 콘솔 기록뿐입니다. 코드는 그대로 둡니다 |
| PWA 설치 동작 | 화면 코드 밖이고 자동화하기 어렵습니다. 서비스 워커 오프라인 실행(ST-06)까지만 봅니다 |
| 실제 Electron 창 | `e2e`는 Chrome에서 `electronAPI`를 대역으로 시험합니다. 실제 창 확인 결과는 `06-rebuild.md`에 따로 적습니다 |
| 파일 내용 해석 | `src/core`의 일이고 `tests/core`에 시험이 있습니다. 여기서는 화면까지 이어지는지만 봅니다 |

## 문서와 코드가 다른 곳

코드 동작을 유지하고, 문서는 이번 범위가 아니라 고치지 않았습니다.

| 문서 | 내용 | 실제 코드 |
|------|------|----------|
| `USER_GUIDE.md` 화이트아웃 | ← 뒤 →는 "화이트아웃만 해제, 학생 B 유지" | 다음 학생으로 갑니다. 마지막 학생일 때만 유지합니다 (WO-07) |
| `USER_GUIDE.md` 발표 시작 | "전체 화면 모드로 전환됩니다" | 자동 전환은 없고 F를 눌러야 합니다 |
| `USER_GUIDE.md` 발표 시작 | 학생을 고른 뒤 시작 (선택사항) | 항상 첫 학생부터 시작합니다 (PR-01) |
| `USER_GUIDE.md` Q3 | 우측 상단 전체화면 버튼 | 전체화면을 켜는 버튼은 없고 해제 버튼만 있습니다 (FS-02) |
| `USER_GUIDE.md`, `README.md` | "상단의 표준 서식 다운로드" 버튼, "엑셀 파일 선택" 버튼, "우측 패널 하단" | 지금 화면과도 이름과 위치가 다릅니다. 새 화면에 맞춘 고침이 필요합니다 |
| `ScoreShow.md` | 매핑 화면, 내보내기, 세션 전용 모드, 경고 표시, 페이드 전환, "앱 설치" 버튼, `connect-src 'none'` | 없습니다. 설계서의 계획으로 봅니다 |
| `README.md`, `ScoreShow.md` | 네트워크 요청 완전 차단 | 웹 버전의 표준 서식 받기는 GitHub 주소만 허용합니다 (TP-01). Electron은 네트워크를 쓰지 않습니다 |

## 코드에서 찾은 쓰이지 않는 것

`electronAPI.downloadTemplate`, `electronAPI.focusWindow`는 정의만 있고 화면에서 부르지 않습니다. `isEditMode`는 데이터를 지워도 유지되어, 수정 중 삭제하고 새 파일을 올리면 수정 상태로 시작합니다. 스토어 동작이라 그대로 둡니다.
