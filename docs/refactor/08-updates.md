# 새 버전 확인

작성일 2026-11-02. 패밀리 규칙(`gnilab/CLAUDE.md`)과 어울림 구현(`electron/updater.ts`)을 따릅니다.

## 동작

- Windows 설치본만 켠 지 5초 뒤 GitHub에서 한 번 확인합니다. 맥, 리눅스, 웹판, 개발 모드는 확인하지 않습니다. ScoreShow에는 USB판이 없습니다.
- `새 버전(1.3.0)이 있습니다.` [설치] [나중에]. [설치]를 누르기 전에는 내려받지 않습니다.
- 내려받은 뒤 `설치 준비가 끝났습니다. 앱을 닫으면 설치됩니다.` [지금 다시 시작] [닫기].
- 나중에를 누르면 이번 실행에서만 닫히고 다음에 켤 때 다시 묻습니다.
- 확인 실패는 조용히 넘깁니다. 교사가 직접 누른 확인과 내려받기만 결과를 보여 줍니다.

## 어울림과 다른 점

| 항목 | 어울림 | ScoreShow | 이유 |
| --- | --- | --- | --- |
| 알림 자리 | 화면 아래 알림(토스트) | 사이드바 맨 아래 칸, 전체화면에서 숨김 | 학생이 모니터 앞에 있을 때 눈에 띄지 않게 합니다 |
| 스위치 자리 | 설정 창 | 사용 가이드 창의 '새 버전' 구역 | 설정 창이 없고, `brand/DESIGN.md`도 설정 창이 없는 앱은 버전을 이 창에 둡니다 |
| 지금 다시 시작 | `quitAndInstall()` | `quitAndInstall(true, true)` | ScoreShow 설치 프로그램은 단계형이라, 기본값이면 설치 창이 다시 뜹니다 |
| 설치 파일 이름 | `Eoullim-Setup-<버전>.exe` | `ScoreShow-Setup-<버전>.exe` | GitHub가 파일 이름의 빈칸을 바꿔 `latest.yml`과 어긋나지 않게 빈칸을 뺐습니다 |

## 통신

- 화면 쪽 코드는 지금처럼 외부 요청이 막혀 있습니다(`src/core/no-network.ts`). 확인은 화면 밖의 `electron/updater.cjs`만 합니다.
- 시험에서 앱이 요청한 것은 `latest.yml`, 설치 파일, `.blockmap`뿐입니다.
- 통일 문구 `인터넷은 새 버전 확인에만 씁니다.`는 확인 기능이 있는 판에서만 보입니다.

## 시험

- `e2e/update-smoke.mjs`: 포장한 앱과 이 컴퓨터의 시험용 서버로 위 동작을 확인합니다. 자료는 임시 폴더에 두고, 실행 전에 임시 폴더를 쓰는지부터 검사합니다.
- 확인하지 못한 것: GitHub 실제 릴리스에서 받아 설치하는 과정. 시험에서는 설치 단계 직전에 멈춥니다. 다음 릴리스를 올린 뒤 그다음 릴리스에서 처음으로 끝까지 확인됩니다.
